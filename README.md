# SDLC — шаблон проекта

**Автор:** Усевич Кристина, гр. 450502  
**Дисциплина:** Жизненный цикл разработки программного обеспечения  

**Описание проекта:** Репозиторий предназначен для выполнения лабораторных заданий по дисциплине «Жизненный цикл разработки ПО». В ветке `ProjectTemplate` подготовлен пустой Java-проект (`proj`, JDK 17), в котором в дальнейшем будут выполняться проектирование и разработка.

## Структура

```
proj/          # пустой Java-проект (Maven / Spring Boot, JDK 17)
srs/, sdd/, adr/, docs/   # шаблоны проектной документации из исходного репозитория
```

## Запуск пустого проекта

```bash
cd proj
./mvnw spring-boot:run
```

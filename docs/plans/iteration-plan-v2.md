# План v2 — изменённый (после первого раунда)

**Продукт:** «Рецептус» 0.1
**Команда:** 1 автор (middle)
**Длина итерации:** 2 недели
**Старт:** 16.11.2026
**Ставка:** автор — 750 BYN за неделю

Что изменилось по договорённости 06.11.2026 (подробно — журнал CH-01…CH-11 в `priorities.md`):

* свои рецепты подняты выше поиска (приоритеты 30 и 40);
* экраны не перерисовываются — они уже согласованы диаграммами SysML;
* стандартные компоненты Swing вместо собственных (дата, сортировка, форма правки);
* готовая библиотека JSON вместо собственной записи файлов;
* стартовый набор — 15 рецептов вместо 50;
* полный подбор рецептов с количествами заказчик оставил: это смысл продукта;
* 15 недель → 10 недель, сдача 24.01.2027.

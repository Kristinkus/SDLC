# Утилита «Высота и длина»

Swing-приложение для конвертации длины по шаблону **MVC с активной моделью**.

## Запуск в IntelliJ IDEA

1. Откройте проект.
2. Дождитесь импорта Maven (`pom.xml`).
3. Запустите класс `lab_lcdsw.high_length.Main` (Run).

## Структура

```
src/main/java/lab_lcdsw/high_length/
  Main.java
  model/LengthUnit.java
  model/LengthModel.java      # активная модель + Observer
  view/MainView.java
  view/InputDialog.java
  controller/LengthController.java
docs/
  mvc.puml
  sysml_v2.txt
  Отчёт_ЛР1_Высота_и_длина.docx
```
